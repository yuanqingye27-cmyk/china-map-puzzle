# 怎么让同学真的玩到（实操）

> 当前阶段：**技术已完成，等待真人验证。**
> 在拿到反馈之前，不做任何新功能开发。

---

## 一句话说明这是什么

> 一个中国地图拼图小游戏：把区县碎片拖到地图上正确的位置，拼对了会弹出这个区县的介绍。
> 全国 363 张地图都能玩，目前成都和乐山的资料是完整的。

- **要多久**：拼一关大概 2 分钟
- **需要什么**：什么都不用装。发链接对方点开就能玩；也可以发文件让对方双击

## 方式 A：公网链接（**首选，不在同一个 WiFi 也能玩**）

一条命令，拿到一个 `https://...` 地址。**手机 / 电脑 / 微信点开就能玩** ——
不需要和你连同一个 WiFi、不用装任何东西、不用注册账号、不用备案。

```bash
cd /Users/apple/Desktop/deepseekharness
node tools/share-online.js --map=sichuan
```

它自己做完两件事（起本地服务 + 建 SSH 反向隧道），然后把链接打印出来，
**连班群那段话都替你填好了链接**：

```
  ✅ 公网链接已生成（手机 / 电脑 / 微信都能直接打开）

     https://xxxxxxxx.lhr.life/?map=sichuan
```

**⚠ 必须知道的两件事**：

1. **这个终端窗口要一直开着**，链接才有效。关窗口 / Ctrl+C / 电脑休眠，链接立刻失效。
2. 隧道是**公网可达**的 —— 拿到链接的人都能访问。测完请 Ctrl+C 关掉。

> 想要**永久**地址（关了电脑也活着），得部署到静态托管。三条都免费，
> 但都要你自己的账号：Cloudflare Pages（`*.pages.dev`，不用备案）、
> 腾讯云 EdgeOne Pages（国内节点，要实名）、GitHub Pages（国内偏慢）。
> 这一步需要你注册账号，我帮不了你登录。

## 方式 B：局域网链接（同一 WiFi，不依赖外网）

适合班级/宿舍：**你电脑不联网也能用**，同学连同一个 WiFi 点链接就玩。

同学**点一下链接就能玩**，不用下载、不用保存、不用装东西。

```bash
cd /Users/apple/Desktop/deepseekharness
node tools/serve.js --map=sichuan
```

它会打印：

```
★ 发到群里，同学点开就能玩（手机要连同一个 WiFi）：
      http://192.168.124.14:8000/?map=sichuan   （en0）
```

把那条链接复制出去就行。想换起始地图，改 `?map=` 后面的 id（`sichuan` / `china` / `leshan` / `chengdu`）。

**用完 `Ctrl+C` 关掉。** 这是一个只读的本地服务，同学连不上就废了，所以演示期间要一直开着。

### 可能踩到的两个坑

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 你电脑能开，同学手机打不开 | **校园网常开"客户端隔离"**（禁止设备之间互访） | 让同学（或你）**开手机热点**，电脑连上热点，重启服务，链接里的 IP 通常会变成 `172.20.10.x` |
| 打印的是 `localhost` 或者没有局域网那行 | 电脑没连 WiFi / 只有有线 | 连上 WiFi 再启动，或把有线网卡的地址给同学试 |

> 换网络之后 IP 会变，**必须重新跑一次 `node tools/serve.js` 拿新链接**。

## 方式 C：单文件离线包（发给不在同一个 WiFi 的人 / 用电脑的人）

文件已经生成好了：

```
out/地图拼图-四川省.html        （1.3 MB，22 张地图：四川省 + 成都/乐山/自贡… …）
```

重新生成（改了地图数据之后才需要）：

```bash
node tools/bundle.js --province=sichuan
```

### 电脑端

**双击文件即可玩。** 不需要联网、不需要服务器、不需要安装任何东西。

### 微信 / 手机端（**实测步骤，微信不预览 .html**）

微信收到 `.html` 文件后**不会直接显示内容**，对方必须手动走完这几步才能打开：

1. 在聊天里**长按**那个文件
2. 选 **「用其他应用打开」**
3. iPhone：选 **「存储到"文件"」** → 打开「文件」App → 点这个文件
   Android：直接选一个**浏览器**打开
4. 打开后就能玩（离线，不耗流量）

> **实测提醒**：手机上要 3~4 步，多数人走到第 2 步就放弃了。
> 所以**手机端优先用方式 A 的链接**，方式 C 留给用电脑的人，或者你当面帮对方打开一次。

### 想让更多人玩

```bash
node tools/bundle.js --all              # 全国版，18.5 MB，363 张地图
node tools/bundle.js --maps=chengdu     # 只打一张地图，约 300 KB
```

全国版体积大，**适合在电脑上玩**，手机上解析会明显变慢。

## 发到班群的话（直接复制下面这段）

> `node tools/share-online.js` **会直接把下面这段打印出来、链接已经填好**，
> 不用手改。这里放一份是为了你随手能拿到。

```
我在做一个中国地图拼图小游戏，想请你帮我试玩一下。
点这个链接就能玩：
https://xxxxxxxx.lhr.life/?map=sichuan

拼一关大概 2 分钟。
玩完能回答我三个问题吗？
① 第一关有没有卡住？
② 拼对后的介绍你会看吗？
③ 玩完一关还想继续吗？
谢谢！
```

> **发之前记得把链接换成你刚跑出来的那一条**（`share-online.js` 打印的那段已经是好的）。
> 换网络、重启隧道之后地址会变，别用这份文档里的示例地址。

### 为什么要问这三个问题

| 问题 | 它在验证什么 | 如果答案是"否" |
| --- | --- | --- |
| ① 第一关有没有卡住 | **能不能玩**（技术可用性） | 是 bug，把地图名告诉我，我按 `--only-maps=<id>` 精查 |
| ② 拼对后的介绍你会看吗 | **内容要不要**（值不值得补那 3132 条） | 该改资料卡，不是继续补数量 |
| ③ 玩完一关还想继续吗 | **玩法留不留人** | 才轮到改玩法 |

**不要问"你觉得怎么样"** —— 那只会收到"挺好的"，什么都验证不了。
